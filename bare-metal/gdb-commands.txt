c continue: go to next breakpoint
n next: 		next line/no inside the function calls
s step: 		next line/w calls
ni (nexti):	continues only one assembly code next
finish:		runs until the func ends.

b <func/line>:	Puts a breakpoint within input: b main.c:25
b <address>:		Puts a breakpoint within that address: b *0x0800018c
d <id>:			Removes breakpoint

watch *<address>: Watches the address and stops the running when change

monitor mdw <address> [count]: Memory Display Word
monitor mww <address> <value>: Memory write word
